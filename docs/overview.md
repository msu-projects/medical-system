## 🏥 Project Plan: School Clinic Management System

---

### 📌 Project Overview

A simple and efficient **School Clinic Management System** for educational institutions that leverages **QR code technology** to streamline patient check-ins, medical record access, and healthcare delivery. Students can log in to view their own health records, while clinic staff manage consultations and medicine dispensing.

---

### 👥 User Roles (4 Roles + System Admin)

| Role                            | Description                                                               |
| ------------------------------- | ------------------------------------------------------------------------- |
| **System Admin**                | Manages accounts, system settings, and overall data                       |
| **School Nurse / Clinic Staff** | Manages consultations, records, and medicine inventory                    |
| **School Doctor**               | Views records, issues diagnoses and prescriptions                         |
| **Student**                     | Logs in to view personal health records, uses QR code for clinic check-in |
| **Teacher / Faculty**           | Requests health clearance, views student health status (limited)          |

---

### ⚙️ Core Features

**QR Code Module**

- Each student gets a unique QR code (generated upon registration)
- Scanning the QR at the clinic instantly pulls up the student's medical profile
- Used for fast check-in without manual searching

**Student Portal**

- Secure login for students
- View personal medical history, consultation logs, prescriptions
- Download health clearance

**Clinic Staff Dashboard**

- Scan QR to check in a student
- Log consultation details (symptoms, diagnosis, medicines given)
- Manage medicine inventory (stock in/out)

**Doctor Module**

- View patient consultation records
- Issue prescriptions and medical certificates

**Faculty Portal**

- View basic health clearance status of students
- Request medical certificates
